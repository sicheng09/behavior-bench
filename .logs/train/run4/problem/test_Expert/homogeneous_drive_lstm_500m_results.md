### Expert 交通是什么？

**Expert（专家轨迹回放）** 不是学习策略，也不是 IDM 公式：他车在 C 引擎里设为 `MOVEMENT_EXPERT`，每步由 `move_expert()` **直接写入该时刻的 WOMD 真值位姿**（`traj_x/y/heading[t]`）。Python 侧 `ExpertPlanner.plan()` 只返回 dummy action，真正控制发生在仿真内核。

直觉上：

1. **开环、非反应**：他车不感知 ego，不会为避让而改道/减速；轨迹在数据里已固定。  
2. **可含静止 / 已消失车辆**：某时刻 `traj_valid=0` 时车辆被移出；仍有效但速度≈0 的点会表现为「停在路上的障碍」。  
3. **分布更「人类」也更「难」**：相对车道跟随 IDM，专家流有真实变道、交互与停等；相对同权 PPO 自博弈，专家**不会配合** ego 的挤占。

与 IDM / PPO 交通对比：

| | Expert 交通 | IDM 交通 | PPO 交通（同权） |
| --- | --- | --- | --- |
| 决策 | 录制轨迹开环回放 | 公式跟驰 + 车道跟随 | 学习策略 |
| 是否反应 ego | **否** | 纵向对前车反应；横向钝 | 是（博弈） |
| 可调参数 | 无（数据即行为） | \(v_0,T,a,b,s_0\) | 权重 |
| 本实验用途 | **人类交通 held-out** | 规则交通主协议 | 训练分布内对照 |

## 4. Expert 测试碰撞分析：碰撞是怎么引发的？

数据：各 run `collision_snapshots.json`（首碰 + `collision_classifier`）。  
设定：**1× PPO ego + 全员 Expert 开环回放**。

### 4.1 类型总览

| Run | 碰撞 maps | Stopped | Front | Lateral | Rear | At-fault / 碰撞 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| run1 | 92 | **37（40%）** | 28（30%） | 21（23%） | 6 | 84/92（**91%**） |
| run4_r1 | 85 | **36（42%）** | 23（27%） | 23（27%） | 3 | 78/85（**92%**） |
| run4_r2 | 99 | 30（30%） | 27（27%） | **33（33%）** | 9 | 90/99（**91%**） |

与 vs IDM（Lateral 为主、At-fault/碰撞约 54–79%）对照：

| 特征 | vs IDM | vs Expert |
| --- | --- | --- |
| 主桶 | Lateral | **Stopped + Front**（Lateral 仍重要） |
| At-fault / 碰撞 | ~54–79% | **~91%** |
| 碰撞 maps | ~32–35 | **~85–99** |

**Expert 特有主因：`STOPPED_TRACK_COLLISION`**——撞上轨迹中近静止的录制车辆（停等/拥堵/无效运动段），分类下几乎全责。

### 4.2 各类型机制

| 类型 | 几何 / 责任（简） | 在 Expert 设定下的成因 |
| --- | --- | --- |
| **STOPPED_*** | 他车近零速；track 静止常责 | ego 冲进录制静止车；专家**不会挪开** |
| **ACTIVE_FRONT** | 他车在前且闭合；**一律 at-fault** | 专家按原轨迹走/刹；ego 跟车不足或抢行 |
| **ACTIVE_LATERAL** | 侧方接触；跨多车道才责 | 并线/超车时专家横向占位固定，不让道 |
| **ACTIVE_REAR** | 他车在后；通常非责 | 后方专家贴上；次数少 |

#### A. 静止轨迹碰撞（最大桶，几乎全责）

| 特征 | run1 | run4_r1 | run4_r2 |
| --- | ---: | ---: | ---: |
| 次数 | 37 | 36 | 30 |
| at-fault | 37/37 | 36/36 | 30/30 |
| 中位 ego / other 速度 | 15.0 / **0.0** | 15.2 / **0.0** | 16.1 / **0.0** |
| 中位 \|lat\| / \|lon\| | 1.42 / 3.42 m | 1.53 / 3.75 m | 1.71 / 3.81 m |
| 发生 step 中位 | ~22 | ~23 | ~23 |

**因果链**：WOMD 中大量停等/缓行被原样回放 → 同质 ego 偏快、对「不会动的障碍车」预留不足 → 早期 step 即责碰。  
三路共有 **24** 张 Stopped 难图（见 §4.5），是 Expert 协议上最稳定的失败簇。

#### B. 前方碰撞（次主因，全责）

| 特征 | run1 | run4_r1 | run4_r2 |
| --- | ---: | ---: | ---: |
| 次数 | 28 | 23 | 27 |
| at-fault | 28/28 | 23/23 | 27/27 |
| 中位 ego / expert 速度 | 15.2 / 4.5 | 15.1 / 3.6 | 15.4 / 4.2 |
| 中位闭合 Δv | ~9.5 m/s | ~9.6 | ~9.3 |
| 同向（\|Δheading\|&lt;30°） | 20/28 | 14/23 | 23/27 |

专家前车常更慢或按录制减速；ego 闭合速度高 → 追尾式 Front。与 IDM Front 同类，但 Expert 上次数约为 IDM 的 **3–4×**。

#### C. 侧向擦碰（第三桶；run4_r2 抬升）

| 特征 | run1 | run4_r1 | run4_r2 |
| --- | ---: | ---: | ---: |
| 次数 | 21 | 23 | **33** |
| at-fault | 19/21（90%） | 19/23（83%） | **33/33（100%）** |
| 中位 ego / other | 13.3 / 6.0 | 14.4 / 7.5 | 12.0 / 6.0 |
| ego 明显更快 | 17/21 | 19/23 | 29/33 |
| 他车多在侧后（fwd 中位） | −1.5 m | −3.0 m | −1.6 m |

相对 IDM：Expert 侧向 **at-fault 比例更高**（专家不躲 + 分类更常判跨车道）。run4_r2 的 Coll/Fault 偏高，与 Lateral 从 21–23 升到 33、且全责有关。

#### D. 后方（次要）

每 run 仅 3–9 起，**at-fault = 0**；不是主矛盾。

### 4.3 和评测部署的关系

```text
训练：周围多是会反应的同质 PPO
   ↓ 分布偏移
评测：周围全是开环 Expert（不躲、可静止、轨迹固定）
   ↓
撞静止录制车 → Stopped（全责，最大桶）
跟不住/抢行 → Front（全责）
贴着变道超车 → Lateral（高责）
```

因此 Coll≈15% **不是**「专家主动攻击」，而是 **非反应人类轨迹 + 进攻型同质策略** 的结构性摩擦；At-fault≈Coll 说明失败几乎都记在 ego 上。

### 4.4 优化含义（针对 Expert 测试）

| 优先级 | 类型 | 理由 |
| --- | --- | --- |
| **最高** | Stopped | 次数最多、全责、三路高度重叠；对应「静止/缓行障碍」避障与预测 |
| **高** | Front | 全责；跟车/TTC 对慢速专家流 |
| **高（run4_r2）** | Lateral | 抬升总 Coll/Fault；并线净空 |
| 低 | Rear | 样本少且非责 |

相对只优化 IDM（侧向+跟车）：Expert 要求额外覆盖 **开环静止障碍与不配合交互**，否则 Goal/Coll 很难同时接近 vs IDM 水平。

## 5. 指标口径（简要）

与 IDM 文档相同：Goal / Collision / At-fault / Offroad 为有效 map 上跨图均值；At-fault 为「该 map 是否发生责任碰撞」的发生率。  
`collision_snapshots.json` 条数 = 发生碰撞的 map 数（每图首碰一次）；本三路分别为 92 / 85 / 99，与 `collision_rate × 589` 一致。

## 6. 结论

1. **Expert 是明显更难的 held-out 交通**：相对 vs IDM，同质 Drive+LSTM 的 Goal 降约 10pp，Coll/Fault 升到约 **15% / 14%** 量级。  
2. **失败结构不同于 IDM**：Expert 上 **Stopped（静止轨迹）** 与 **Front** 主导，且 **>90%** 碰撞判责；IDM 上则以 Lateral 为主。  
3. **三路种子结论一致**：没有某一 run 在 Expert 上「偶然过关」；run4_r1 略好、run4_r2 略差，但都远差于 vs IDM。  
4. **难例可复现**：碰撞 map Jaccard≈0.53–0.64，三路共撞 58 张；Stopped 簇尤其稳定——适合作为后续避障/交互改进的回归集。  
5. **含义**：仅在同质 PPO 或 IDM 上好看，不足以说明对人类交通鲁棒；若论文要声称泛化，Expert（及类似开环人类流）应作为硬门槛之一。
